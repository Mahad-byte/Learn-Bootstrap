# Pro UI

A basic UI layout I built while learning **HTML, CSS, and Bootstrap**. It's a practice project that mimics the look of a web builder / dashboard-style interface.

## What's Inside

- **Fixed sidebar** on the left with icon buttons (Font Awesome)
- **Fixed header** with action buttons (Export, Import) and device preview icons (mobile / desktop / laptop)
- **Responsive navbar** using Bootstrap's `nav-pills` with a collapsible mobile menu
- **Hero section** with a two-column layout, buttons, and a floating image animation
- **Content section** with an image and text side by side

## Tech Used

- HTML5
- CSS3 (custom styles in `style.css`)
- [Bootstrap 5.3.8](https://getbootstrap.com/) (via CDN)
- [Font Awesome 6.4.0](https://fontawesome.com/) (via CDN)

## Getting Started

No build tools needed — just open `index.html` in your browser, or use a live server extension (e.g. VS Code Live Server) for auto-reload.
